# Gameplay-Konzept: EU5 Culture Rework

Hier steht ausschließlich **was im Spiel geschehen soll und warum**. Keine Script-Syntax, Dateipfade, Hooks oder Implementierungspläne. Technische Machbarkeit wird getrennt unter [../technical/](../technical/README.md) dokumentiert.

## Leitbild

Kulturelle Beziehungen sind historische, gesellschaftliche Prozesse. Sie ändern sich kontinuierlich und gerichtet zwischen zwei Kulturen, nicht per Knopfdruck oder mit künstlichen jahrzehntelangen Cooldowns. Staaten beeinflussen die Entwicklung mittelbar durch ihre Politik, Diplomatie und ihr Verhalten.
